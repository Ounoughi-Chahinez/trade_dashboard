Methodology overview

Historical trade values are taken from BACI. The forecasting model is a Random Forest trained on data from 2012 to 2024, using bilateral trade together with exporter and importer macro features, bilateral distance, and HS6 product information.

Future macro features are based on SSP2 trajectories and were aligned to observed World Bank levels using a country-specific ratio anchoring approach. The anchor year is 2015, and the monetary variables are expressed in constant 2015 USD.

For each country, a correction factor was computed as the ratio between the World Bank level and the SSP2 level at the anchor year, and this factor was then applied to the future SSP2 trajectory. This preserves the SSP2 time profile while aligning the level with the observed World Bank baseline.

Future forecasts are displayed at a 5-year frequency. The chart therefore combines historical BACI observations with Random Forest forecasts generated from the corrected macroeconomic feature path.

Optional indicator overlays are drawn from the separate features file. For a selected country, the dashboard displays that country's series. When exporter or importer is set to All, the dashboard uses the average indicator value across countries for each year.
