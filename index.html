Methodology overview

The dashboard combines historical BACI trade observations with forecasted trade paths generated from future macroeconomic trajectories.

For model training, the macroeconomic variables are taken from World Bank (WB) data. For future prediction, the macroeconomic variables are based on SSP2 trajectories corrected and aligned according to the World Bank baseline.

Future feature series are anchored at the country level using 2015 as the anchor year. Monetary values are displayed in constant 2015 USD.

Historical observations cover the period up to 2024, while forecasted values are shown at a 5-year frequency. Multiple forecast variants can be displayed together for direct comparison.

Trade values in the source files are stored in thousands of USD. The dashboard multiplies them by 1000 so the chart displays full dollar amounts.

Optional macro overlays are drawn from the separate features file. For a selected country, the dashboard displays that country’s indicator series. When exporter or importer is set to All, the dashboard uses the average indicator value across countries for each year.
